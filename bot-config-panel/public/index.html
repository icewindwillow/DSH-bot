机器人使用的模型

写进 cordis.patch.yml 的 agent-default-model，决定机器人回复用哪个模型。改完需要重启机器人。官方服务商密钥可在「API 密钥 / QQ 连接」配置。

Our Free Model 是第三方插件提供的模型路由，需先安装并完成对应配置才会出现。上游可能有额度、限流、服务条款与可用性变化，不保证长期或无限免费；不要使用来源不明的共享密钥。

首次使用：填写你需要的服务

① 填写 QQ 机器人连接信息；② 按所选模型或功能填写对应 API 密钥，不用全部填写；③ 保存后重启机器人。模型仍需到「模型与推理」选择，保存密钥不会自动切换模型，也不代表权限或额度已验证。

密钥只保存在当前 profile 的 .bot-secrets.json（文件权限 600）。这是本机明文文件，并非加密保险库；不要分享、上传到 Git 或截图泄露。请仅在可信的本机浏览器使用面板。
继承环境变量优先：启动进程已有非空环境变量时，会优先使用它，本地填写的值不会覆盖它。面板只显示「是否配置 / 来源」，绝不显示已有值或末尾。留空 = 保留；勾选删除 = 只清除本地副本，无法清除启动环境中的值。

QQ 机器人连接

QQ 开放平台机器人 AppID 与机器人密钥。使用官方插件支持的 QQBOT_APPID / QQBOT_SECRET，不是个人 QQ 密码；还需完成开放平台机器人权限与插件配置。

模型与辅助功能的 API 密钥

只填你要使用的服务。API 通常按服务商规则计费；配置成功不等于联网、权限、额度验证成功。Our Free Model 通过对应第三方插件安装，不在这里填写所谓「免费 Key」，也不保证长期、无限免费。

生图（默认关闭）

费用取决于所选模型：OpenAI 按官方规则计费（OPENAI_API_KEY）；硅基流动 Kwai-Kolors/Kolors 当前免费（SILICONFLOW_API_KEY，需实名认证）；Cloudflare flux-1-schnell 走每日免费额度（CLOUDFLARE_API_TOKEN + CLOUDFLARE_ACCOUNT_ID）。保存 Key 不会自动启用生图，空白或缺失 Key 不会发起生图请求。

权限：只有主人、image-gen 这个生图技能的受众、或好感度达到门槛（缺省 60）的成员能画。有权限的人直接用大白话要图就行，不必打 /生图；没权限的人不会产生任何请求。

Cloudflare 的 flux-1-schnell 基本只认英文：发送前会先让聊天模型理解中文意图、补全画面，再改写成一条英文提示词（多 1–2 秒）；改写失败则按原文发送并在回执里注明。想换改写用的模型用 QQBOT_IMAGE_PROMPT_PROVIDER / QQBOT_IMAGE_PROMPT_MODEL。

每次单张、不自动重试；只发送本轮新 prompt，不附带群历史或参考图。请求固定发往所选模型对应的官方接口，不经过自定义聊天网关，也不接受自定义接口 URL。硅基流动返回 1 小时有效链接，工具只下载一次并校验 PNG/JPEG；免费模型默认带「AI 生成」水印。

生图设置保存后动态生效，无需重启；新填或更换 Key 需要重启机器人才会注入启动环境（运行时也会直接读 ~/.dsh/.credentials.yaml）。保存设置和刷新状态不会调用生图接口，也不验证额度或权限。

能发图的人由权限名单控制；同一时刻只画一张，不再有冷却或每小时上限
